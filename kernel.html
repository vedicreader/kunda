kernel

one running kernel: execute and complete over the shell channel, variables over its in-kernel

Run one local or gateway kernel. Execution returns nbformat outputs. Inspection uses the Dhrishti HTTP API.

KERNELS lists supported Python launchers. Unknown launcher names use ipykernel.

give_up_after

async def give_up_after(
    coro, timeout:float=5.0
):

Await coro, then stop waiting rather than hold the caller open. Failing to close is not news.

give_up_after stops waiting for shutdown after the timeout. A host that closes several kernels at once wraps the close in it, so one kernel that never answers cannot hold the rest up.

t = time.time()
await give_up_after(asyncio.sleep(30), timeout=.05)      # the deadline ends this, not the sleep
async def never_answers(): raise RuntimeError('the kernel never answered')
await give_up_after(never_answers()), time.time() - t < 1

Feed

def Feed(
    maxsize:int=1000
):

Hand messages to subscribers from a bounded queue, so whatever produces them never waits on whoever reads them.

Feed is how a kernel tells its host about traffic no request asked for: widget comms, output from a comm handler, and {'type': 'kernel_restart'} or {'type': 'kernel_gone'}. The router puts and returns at once. One task delivers to each subscriber in turn, and a subscriber that falls maxsize messages behind loses the oldest, counted in dropped, so a stalled browser tab can neither block the kernel’s reader nor grow memory without bound.

f, seen = Feed(maxsize=2), []
f.put('before anyone listened')
f.subscribe(seen.append)
for i in range(4): f.put(i)
await f.flush()
seen, f.dropped
([2, 3], 2)

MessageRouter

def MessageRouter(
    *args, **kwargs
):

The one reader of a kernel’s iopub and shell replies, sending each message to its run, its waiter or the subscribers.

MessageRouter is what Kernel and GatewayKernel share: each transport feeds every inbound message to _route, and nothing else reads the kernel. A shell reply resolves the request that is waiting for it, so complete, inspect_obj, comm_info and execute overlap without stealing each other’s replies. Output parented to the running execute joins its outputs. Comm traffic, and output whose request is not a running execute, such as a print inside a comm’s on_msg handler, go whole to the subscribers, buffers included.

An Output widget changes where output belongs. While its msg_id state names a request, the frontend shows that request’s output inside the widget, so the router tags it with the widget’s output_comm_id and gives it to the subscribers instead of the cell. Here a router with no kernel under it is fed the messages ipywidgets sends for with out: print(...) inside a cell:

class Wire(MessageRouter):
    "A router fed by hand."
    comms = True
    def __init__(self): self._init_router()

def msg(t, content, parent='cell-1'): return {'header': {'msg_type': t}, 'parent_header': {'msg_id': parent}, 'content': content, 'channel': 'iopub'}
state = lambda msg_id: {'comm_id': 'out-1', 'data': {'method': 'update', 'state': {'msg_id': msg_id}}}
w, got, run = Wire(), [], _Run()
w.subscribe(got.append)
w._runs['cell-1'] = run
for m in [msg('comm_open', {'comm_id': 'out-1', 'target_name': 'jupyter.widget', 'data': {'state': {'_model_name': 'OutputModel', 'msg_id': ''}}}),
          msg('comm_msg', state('cell-1')), msg('stream', {'name': 'stdout', 'text': 'inside the widget\n'}),
          msg('comm_msg', state('')), msg('stream', {'name': 'stdout', 'text': 'in the cell\n'})]: w._route(m)
await w.feed.flush()
run.outs, [(m['msg_type'], m.get('output_comm_id')) for m in got]
([{'output_type': 'stream', 'name': 'stdout', 'text': 'in the cell\n'}],
 [('comm_open', None),
  ('comm_msg', None),
  ('stream', 'out-1'),
  ('comm_msg', None)])

Kernel

def Kernel(
    cwd:NoneType=None, name:NoneType=None, python:NoneType=None, inspect:bool=True, agent:str='restricted',
    port:int=8000, kernel:str='ipykernel', lang:str='python',
    known:NoneType=None, # the host's `{language: kernelspec}`, handed down by the pool
    install:str='', # what would install a kernel for `lang`, for the error when none is
):

One ipykernel process: execute/complete over jupyter_client, live variables over its in-kernel.

Kernel owns one local kernel process and its Jupyter client. start waits for the kernel and then starts Dhrishti when inspection is enabled.

k = Kernel(kernel='not-a-kernel', inspect=False)
j = Kernel(cwd='/proj', lang='julia', inspect=True)
k.kernel, (j.kernel, j.inspect, await j.chdir('/proj'))
('ipykernel', ('ipykernel', False, False))

Execution on a stopped kernel returns a failed ExecOutcome. One reader per channel feeds the router from start until shutdown, and restart replaces it, so a request never reads the kernel itself. A timeout bounds the whole run, and a run that outlives it comes back failed with the outputs it had.

k.alive, k.pid, (await k.execute('1+1')).error, await k.complete('1+', 2), await k.inspect_obj('1+', 2)
(False, None, 'kernel is not running', {'from': 2, 'matches': []}, '')

Registered language kernels use their installed kernelspec. A missing kernelspec raises KernelStartError.

_as_output converts one IOPub message to an nbformat output. Messages without output return None.

GatewayKernel

def GatewayKernel(
    gateway, cwd:NoneType=None, name:NoneType=None, python:NoneType=None, inspect:bool=True, agent:str='restricted',
    port:int=8000, kernel:str='ipykernel'
):

The Kernel interface over jupygate + jupyasyncclient, so a kernel outlives a client reconnect.

GatewayKernel implements the Kernel interface over a gateway WebSocket. The gateway owns the kernel process. The client’s reply futures answer complete, inspect_obj and comm_info, and everything else reaches the router through on_jmsg, which outlives a websocket reconnect. jupygate drops the frames in flight when that websocket dies, so a run that has heard nothing for QUIET seconds asks the kernel for kernel_info on shell. That request queues behind the execute, so an answer while the run still waits means its reply was lost, and the run comes back with lost=True rather than waiting forever.

gk = GatewayKernel(None, name='nb', inspect=False)
gk.alive, gk.pid, gk.lang, gk._boot_name.startswith('nb:'), (await gk.execute('1+1')).error
(False, None, 'python', True, 'kernel is not running')
